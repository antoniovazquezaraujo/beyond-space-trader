# ADR — Registros de decisiones

Un ADR (*Architecture Decision Record*) es un documento corto que fija una
decisión de diseño: el contexto, lo que se decide, lo que implica y lo que se
descartó. Se numeran (`0001`, `0002`…) y **no se reescriben**: si una decisión
cambia, se añade un ADR nuevo que la sustituye y se marca el viejo como
*sustituido* en su cabecera.
